# VENHER · EDU — сторінка прямого ефіру

Ця папка повністю готова для завантаження на GitHub Pages або інший статичний хостинг.

## Важливо

Завантажуйте **весь вміст папки**, а не лише `index.html`.

У корені репозиторію мають бути:

- `index.html`
- `styles.css`
- `script.js`
- папка `assets`

У папці `assets` уже знаходяться всі фото та шрифти, необхідні для дизайну.

Якщо сторінка має відкриватися за адресою на кшталт `site.com/efir`, завантажте **весь цей комплект** у папку `efir` репозиторію. Усередині `efir` файл `index.html`, файли стилів і папка `assets` мають лежати разом.

## GitHub Pages

1. Створіть новий репозиторій на GitHub.
2. Завантажте в нього весь вміст цієї папки.
3. Відкрийте `Settings` → `Pages`.
4. У розділі `Build and deployment` виберіть `Deploy from a branch`.
5. Виберіть гілку `main` і папку `/ (root)`.
6. Натисніть `Save`.
