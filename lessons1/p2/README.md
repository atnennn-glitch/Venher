## Заявки в Telegram

1. Хостинг повинен підтримувати PHP та вихідні HTTPS-запити.
2. Створіть Telegram-бота через `@BotFather`.
3. Додайте бота в потрібний чат або напишіть йому приватне повідомлення.
4. Скопіюйте `telegram-config.example.php` як `telegram-config.php`.
5. Вставте у новий файл токен бота та ID чату.

`telegram-config.php` містить секретний токен — не публікуйте його в GitHub. Замість файлу також можна встановити змінні середовища `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`.

Текст уроку редагується прямо в `index.html`. Кольори та основні параметри дизайну знаходяться на початку `styles.css`.
